Glossary

EMAIL EXTRACTION GLOSSARY

Key terms every sales professional should know when evaluating email extraction and lead generation tools.

Email Extraction
The process of finding and collecting email addresses from web pages, documents, and other sources. MailHarvest Pro extracts emails live from any page — including PDFs, Excel files, CSVs, and shadow DOM elements that other tools miss.
MX Validation
Mail Exchange record validation confirms a domain has a working email server. MailHarvest Pro validates every extracted email against Google DNS and Cloudflare DNS simultaneously, blocking 3,000+ disposable domains.
Hot / Warm / Cold Scoring
An AI classification system that ranks extracted emails by response likelihood. Hot = C-Suite, Directors, VP-level. Warm = managers, mid-level professionals. Cold = generic inboxes, back-office addresses.
Bulk URL Automation
Submitting a list of URLs for automated email extraction. MailHarvest Pro supports up to 1,000 URLs per run with crawl depth 1–3, dual-tab processing, and automatic session pause/resume.
Shadow DOM
A web technology that hides content inside nested document structures invisible to standard scrapers. MailHarvest Pro penetrates shadow DOM to find emails other tools cannot see — common on modern single-page apps.
CRM-Ready Export
A CSV format pre-structured for direct import into CRM tools without manual mapping. MailHarvest Pro exports First Name, Last Name, Email, Company, Source URL, Score, AI Score, Domain and Date.
Disposable Email Domain
Temporary or throwaway email services that produce invalid leads. MailHarvest Pro blocks 3,000+ known disposable domains during the MX validation pass.
Search Automation
Automated searching across multiple platforms (Google, Bing, LinkedIn, GitHub, WHOIS). MailHarvest Pro runs simultaneous multi-engine searches with 110 country targeting and 7 platform filters.
Lead Generation
The process of identifying and collecting contact information for potential customers. MailHarvest Pro generates leads live from any web source — not a pre-built database — ensuring contacts are current.
Local Processing
All extraction, scoring, and validation runs inside the browser on the user's machine. MailHarvest Pro has zero server infrastructure — your leads never leave your computer.
